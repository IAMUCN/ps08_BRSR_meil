# Agent brief

Start every session by reading the project context and progress below. Follow the "How we work" rules in
`PROGRESS.md`.

- `CONTEXT.md` is the live state: what is uncommitted or in flight, what is waiting on the owner, the machine and
  environment facts, how the owner works, and traps already hit. **Rewrite it at the end of every session** (its last
  section says how).
- `PROGRESS.md` is the history: what each phase delivered and the open items. **Update it at the end of each phase**
  as described in its last section.
